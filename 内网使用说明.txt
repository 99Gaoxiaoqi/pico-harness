pico-harness 内网部署包
========================

【环境要求】
  - Windows x64
  - Node.js v22+
  - 依赖已安装，并已配置用户级 %USERPROFILE%\.pico\config.json

【唯一启动方式】
  双击 启动TUI.bat，进入交互式 TUI。

  也可在终端运行:
    npx tsx --import ./src/tui/preload-env.ts --env-file=.env src/cli/main.ts

  安装后可在任意项目目录运行:
    pico

【已退役入口】
  one-shot CLI、HTTP/WS、ACP、飞书和 Docker 外壳已移除。
  --prompt、--serve、--acp、--tui 等旧参数不再受支持。

【常用参数】
  运行 pico --help 查看当前受支持的 TUI 启动参数。

【大模型配置】
  Provider、模型和默认路由必须配置在用户级 config.json。
  API Key 可写入权限受保护的 config.json，或由 Provider 的 apiKeyEnv 显式引用。
  裸 LLM_* 环境变量不会自动创建模型路由，只能作为 /provider import-env 的迁移输入。

【注意】
  - 中文乱码时先执行: chcp 65001
  - 日志级别可通过 LOG_LEVEL 调整
