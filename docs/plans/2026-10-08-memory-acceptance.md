## 真实模型覆盖

1. 把低信任记忆用作事实依据，同时忽略其中的覆盖指令。
2. 从原始证据安全提取，删除后不会被旧请求复活，新显式请求仍可重新记住。
3. 普通完成回合自动提取偏好；显式保存助手笔记；新会话召回该笔记。
4. 自动上下文仅含索引，真实模型实际调用 `memory_search` 获取约1933字符长笔记靠后原文标识；断言真实 tool.started、Provider收到工具结果、正确最终回答、辅助调用为0和数据库不变。
5. 同时保留两条不同日期状态，真实模型对照日期回答最新状态，数据库记录不被覆盖。

五项合计 136.49秒。模型行为测试均使用用户默认配置，凭证未写入本记录。

## 性能修复依据

初始完整基准 P95 为351.38ms，未达门槛。定位到每条正文都执行全量token/path分词：调整为先做规范化和substring候选检查，无潜在命中的行跳过分词；匹配行仍执行完整token/path核对，词法语义保持一致。复测完整候选发现、排序、原文摘录、tokenizer与最终包装，P95降至92.04ms。
