# Pico 内置 Relay 实施记录

基线：b6e2ccdc；目标：保留既有直连、权限、配对确认与恢复语义，增加电脑和手机均出站的加密 Relay 通路，以及桌面管理和发行部署。

## 分工与验收清单

- [ ] 主代理：公共协议、加密通道、电脑网关适配、依赖锁与集成。
- [ ] Relay 子任务：邀请注册、认证与有界转发、部署模板、服务集成测试。
- [ ] 手机子任务：连接描述、配对、RPC/事件/成果读取、迁移与恢复测试。
- [ ] 桌面子任务：本机连接管理、后台启动生命周期、打包与 UI 验证。
- [ ] 集成：直连回归、Relay 主路径与故障路径、受影响类型检查与构建。
- [ ] 交付：内测构建、真实模型主路径；公网/真机条件和实际结果单独记录。

## 固定边界

- 业务 Runtime RPC 和权限矩阵不增加通用转发入口。设备批准、授权扩展、项目注册/信任和 daemon 管理仅本机。
- Relay 只路由受限消息，不存业务历史或文件。所有凭据领取、RPC、事件和文件数据在手机与电脑之间加密。
- Relay 单实例、邀请制注册，每台电脑独立接入令牌。服务端仅保存邀请与注册凭据摘要及必要路由元数据。
- 电脑长期身份公钥由二维码绑定；每次手机连接用新随机密钥和双方会话随机量，信封绑定方向与严格序号。不声称首版具备前向保密。不得关闭 WSS 证书校验。
- SavedHost 保留 gatewayId.deviceId；旧直连记录保持可读，连接路线不成为草稿/审阅/缓存身份。
- 连接恢复只恢复读取和订阅，不自动重发命令。已发出却无结果保持 unknown，只有原有幂等操作可按原键恢复。
- 现有网关独立后台进程承担 connector；Desktop Main 通过本机控制通道管理，不让渲染进程持有电脑密钥或注册令牌。
- 不改用户原工作区内容。公共文件由主代理单一维护，各子任务独立 worktree/分支，自检并仅推送任务分支。
