## 固定边界

- 业务 Runtime RPC 和权限矩阵不增加通用转发入口。设备批准、授权扩展、项目注册/信任和 daemon 管理仅本机。
- Relay 只路由受限消息，不存业务历史或文件。所有凭据领取、RPC、事件和文件数据在手机与电脑之间加密。
- Relay 单实例、邀请制注册，每台电脑独立接入令牌。服务端仅保存邀请与注册凭据摘要及必要路由元数据。
- 电脑长期身份公钥由二维码绑定；每次手机连接用新随机密钥和双方会话随机量，信封绑定方向与严格序号。不声称首版具备前向保密。不得关闭 WSS 证书校验。
- SavedHost 保留 gatewayId.deviceId；旧直连记录保持可读，连接路线不成为草稿/审阅/缓存身份。
- 连接恢复只恢复读取和订阅，不自动重发命令。已发出却无结果保持 unknown，只有原有幂等操作可按原键恢复。
- 现有网关独立后台进程承担 connector；Desktop Main 通过本机控制通道管理，不让渲染进程持有电脑密钥或注册令牌。
- 不改用户原工作区内容。公共文件由主代理单一维护，各子任务独立 worktree/分支，自检并仅推送任务分支。

## 对抗性问题与整改

- 原始 300 帧/min 的共享 IP 限额不足以承载连续流式输出。现按手机通道双向统计，默认 6000 帧/32 MiB 每分钟；电脑聚合 60000 帧/1 GiB 每分钟，单通道超限不连带关闭其他通道。
- Relay 背压异常曾可能穿透 Runtime 回调。现在事件 socket 反映真实队列大小，发送失败关闭外网通道，异常不会传播到本机事件回调。
- 手机自撤销曾先关闭通道导致确认丢失。现在先标记撤销并拒绝后续请求，持久化后发送本次确认，再关闭连接。
- 更换邀请失败曾可能覆盖有效接入凭据。现在活动凭据和待确认候选分开保存，同一候选原 token 重试，确认后才替换；更换失败邀请同步更新摘要。
- 网关曾反向依赖手机客户端的加密实现。现在共享实现位于协议子入口，网关、手机各自依赖公共层；二维码编码按 UTF-16 单元处理，避免截断非 BMP 字符。

## 运维与回退

首版按邀请制单实例内测运行，不提供托管账号、离线命令队列、推送、自动唤醒或 P2P 优选。电脑退出应用后网关继续运行；开机恢复依赖用户登录后启动 Desktop。关闭手机连接即可停止网关，保留会话和设备状态；直连可以重新配置启用。

首次迁移前保留旧安装包与私有状态备份。私钥和接入 token 只在电脑，Relay 只保存摘要及路由元数据；备份不可放入 Git。不要将首版原语组合描述为经过外部审计的完整协议，首版不具备前向保密。正式公网开放前应确认运维归属、固定镜像版本并完成上述外部验收。
