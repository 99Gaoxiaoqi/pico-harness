## 边界与风险

审批、持久化和导出是重点风险；保留权限、会话归属、幂等、路径验证和冲突指纹，不通过隐藏数据或直接注入数据库使测试通过。普通源码写入不自动成为交付物。原用户凭证/项目只读，复制的测试凭证在结束后清除，测试后台进程停止。

子代理只提交/推送任务分支，主代理串行集成。失败时保留集成分支用于定位，不更新目标分支。共享文件 renderer/runtime.ts、公开 contract、IPC 接线由主代理独占；其他文件按任务划分，避免并行共享写入。

TUI 的原生 Terminal CU 访问前次被安全策略禁止，不绕过限制；无法执行的覆盖明确标注。没有外部凭证或危险/系统级操作授权的路径不宣称通过。

## 全新复测重点

1. 批准/拒绝后继续至少一次模型工具步骤，期间无旧卡复活；问答完成后侧聊继承历史正确。

4. Graph/Swarm 子任务正式成功输出后保持成功，用量无需离开页面更新。
5. 添加新项目无需刷新可见；Automation 拒绝保留表单，切 Memory 不出现无关错误。
6. 补测原已通过主链：MCP、Skill、Memory、待办、终端、浏览器、会话管理、诊断。
