# 并发与定时任务验收修复

基线：316f1268。来源：2026-09-16/17 隔离桌面验收。

## 边界与方案

- Jobs：统一服务投影、公开类型和严格响应验证，保留未知字段拒绝，验证真实服务响应全流程。
- Cron：持久化 queued 的可判定所有权，保护活跃 preflight；恢复孤儿/过期 queued 后释放工作区，不补跑或重复执行同一调度。
- Graph：保留根仅监督的权限边界，明确整合/验证先于 finish，委派新 shared Operator 完成整合；不强制把“只交付分支”的合法任务自动合并。
- TaskHost：独立集成 worktree 承接合并及冲突，成功后安全快进目标，目标前移或用户改动则停止。

四项独立工作在隔离 worktree 中进行，主代理在集成分支合并验证；不迁移 schema、不更改用户配置、不改写共享历史。失败时保留隔离现场，主分支保持原状。

## 验收清单

- [ ] Jobs 创建、列出、更新、启停、执行、历史、删除经严格协议解析通过。
- [ ] queued/running 恢复、活跃 owner 保护和分钟幂等集成测试通过。
- [ ] Graph 真实模型双 worktree 并发提交，整合输出先于 finish，原提交可从主分支到达。
- [ ] TaskHost 成功合并、冲突隔离和目标漂移保护集成测试通过。
- [ ] 集成最终状态构建、类型检查及受影响回归通过，桌面 Jobs GUI 复测完成。
