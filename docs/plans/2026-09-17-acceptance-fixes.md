# 并发与定时任务验收修复

基线：316f1268。来源：2026-09-16/17 隔离桌面验收。

## 边界与方案

- Jobs：统一服务投影、公开类型和严格响应验证，保留未知字段拒绝，验证真实服务响应全流程。
- Cron：持久化 queued 的可判定所有权，保护活跃 preflight；恢复孤儿/过期 queued 后释放工作区，不补跑或重复执行同一调度。
- Graph：保留根仅监督的权限边界，明确整合/验证先于 finish，委派新 shared Operator 完成整合；不强制把“只交付分支”的合法任务自动合并。
- TaskHost：独立集成 worktree 承接合并及冲突，成功后安全快进目标，目标前移或用户改动则停止。

四项独立工作在隔离 worktree 中进行，主代理在集成分支合并验证；不迁移 schema、不更改用户配置、不改写共享历史。失败时保留隔离现场，主分支保持原状。

## 实测说明

- Graph 使用用户已配置的 DeepSeek Flash，两轮真实模型测试分别约 122 秒、81 秒。测试提示只描述用户交付目标，不向模型硬编码整合工具步骤；验证两 writer Run 实际重叠、原始提交均可从 main 到达、共享整合 Operator 结果早于 finish，根保持仅三个调度工具。
- 桌面 GUI 使用独立配置和匿名本地模型 fixture，创建后立即出现卡片，刷新无协议错误；暂停状态刷新后保持，恢复启用和立即运行成功，生成会话返回 `AUTOMATION_FIXED_OK`。SQLite 确认整分钟和手动触发各一条 succeeded。
- 更新、历史及删除由真实持久服务经过协议解析的集成测试验证，不冒称 GUI 有本轮未操作的对应入口。测试任务最终暂停并保留证据，隔离 GUI/daemon/fixture 已关闭；没有复制真实凭证至桌面测试目录。
- Cron 快速重启尊重仍有效的 30 秒租约，过期后下一调度恢复孤儿为 failed；不立即接管活跃 preflight、不重放旧触发。
- 首次选择未信任项目时，信任后仍可能短暂保留之前的 FORBIDDEN 提示，刷新即消失；这是独立的 UI 刷新问题，不属于本轮四项修复，不计入已修复范围。

最终 68 条受影响集成测试全部通过（包含 13 条真实 Git 合并/恢复回归）；包构建、根类型检查、Desktop 三目标类型检查、最终桌面打包、定向 ESLint 和架构边界检查通过。独立审查发现的“目标/上游前移后的人工恢复及后续队列基线推进”已修复，并覆盖双任务恢复和不匹配基线继续拒绝。未运行全量测试或 Windows/Linux 验收。
