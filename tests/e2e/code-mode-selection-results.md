# Code Mode 自主选择验收（2026-09-21）

最终版本在 `opencode-go/glm-5.2` 的 30 次受控真实模型试验中通过验收。批量任务触发率由旧提示的 20% 提高到新提示的 100%；单文件任务两组均未触发。这里的百分比是本次样本频率，不是线上通用概率。

## 方法与结果

- 使用真实 `AgentEngine`、持久化 `Session`、`ReadFileTool` 和 QuickJS Code Mode；每次试验新建会话、工作区和测试文件。
- 提供 `read_file` 和 `exec` 两个工具，系统提示保持中性，用户任务不点名 `exec`，不指定代码或强制工具选择。未模拟模型响应。
- 旧提示固定为变更前的 `exec` description；新提示读取生产实现。除此之外，两组装配、任务和文件相同。
- 每个场景、每个版本重复 5 次，共 30 次；串行执行，按重复轮次交替版本顺序。
- “触发”指模型至少生成一次顶层 `exec` 调用；另行统计其执行错误。正确性要求最终 JSON 答案字段与预期完全相符，且确实读取全部目标文件。
- 接受裸 JSON 或完整 JSON 代码块；代码块之后的说明单独记录，不作为计算错误。损坏的 JSON、错误值和漏读仍判失败。
- 验收门槛：新提示批量触发率至少 80%，单文件误触发率至多 20%，15 次新提示任务全部正确且没有 `exec` 执行错误。服务不可用不得解释为“不触发”；连续两次无模型响应时停止采样。

| 场景                        | 每组次数 |  旧提示触发 |    新提示触发 | 旧/新答案正确 |
| --------------------------- | -------: | ----------: | ------------: | ------------: |
| 比较 6 个配置文件的依赖版本 |        5 |         0/5 |           5/5 |      5/5、5/5 |
| 读取 6 份订单并过滤、求和   |        5 |         2/5 |           5/5 |      5/5、5/5 |
| 读取单个配置值              |        5 |         0/5 |           0/5 |      5/5、5/5 |
| 批量任务合计                |       10 | 2/10（20%） | 10/10（100%） |  10/10、10/10 |

最终轮两组 `exec` 执行错误均为 0；请求不可用样本为 0。旧提示有 1 次在合法 JSON 代码块后补充解释，新提示为 0。整轮用时约 168 秒，完成时间为北京时间 2026-09-21 00:25。

## 调试记录与限制

1. 初始测试装配未传会话 ID，OpenCode Go 返回 `MissingSessionID` HTTP 400。修正测试的 `sessionId` 后重新采样；这些没有模型响应的请求不用于估计触发率。
2. 第一版泛化提示的完整对照轮：旧提示批量触发 2/10，新提示 6/10，未达到 80% 门槛；新提示另有一次答案多出右花括号，严格 JSON 校验失败。早期预跑还观察到一次可恢复的脚本错误，因此补充了脚本和执行结果诊断记录。
3. 诊断确认模型曾把读取结果当成 `r.content` 对象；后续版本又出现仅去掉行号、未过滤“共 N 行”状态文本而导致 JSON 解析失败。最终生产提示明确字符串返回契约，并给出按 `数字 + Tab` 提取文件内容的解析示例；不改变工具返回格式或沙箱权限。
4. 补充解析示例后的上一完整轮已达到新提示批量 10/10、单文件 0/5、执行错误 0，但一个正确 JSON 代码块后附加解释，被原先整条消息解析器误归为计算失败。校验器改为读取完整 JSON 代码块并独立记录额外文字，然后在最终测试版本上重新执行上述 30 次验收；此前结果没有覆盖为成功。
5. 这些场景参与过提示调优，不是独立留出的盲测集。样本小、只覆盖一种模型和两个可见工具，不能推断完整产品工具集、多种模型、未知路径探索或复杂写操作中的触发率。仅 10 次全部触发也不能证明真实概率为 100%。
6. 某些调用只并行读取并返回全部结果，没有在代码内完成充分压缩。本次不声称确定的 token、延迟或上下文节省比例。

## 复现

需要已配置的用户默认模型及有效凭证，模型服务调用可能计费。测试不会打印或持久化 Provider 凭证。

```sh
npm run build:packages
RUN_LLM_E2E=1 CODE_MODE_SELECTION_REPEATS=5 \
CODE_MODE_SELECTION_REPORT=/tmp/pico-code-mode-selection.json \
node --import tsx --import @pico/cli/tui/preload-env \
  --test --test-concurrency=1 tests/e2e/code-mode-selection.real-llm.test.ts
```

JSON 报告包含每次试验的选择、真实读取记录、脚本与执行结果、最终答案、格式分类和失败诊断，保留失败样本。默认重复 5 次，可设为 5–20；重新运行会产生新的随机样本。
